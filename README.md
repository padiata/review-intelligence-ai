# Review Intelligence UI

Primera maqueta funcional de la pantalla de revisión y respuesta.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Incluye

- Review de demostración.
- Análisis automático visual.
- Contexto escrito.
- Botón de voz simulado.
- Selector de tono.
- Regeneración local de respuesta.
- Flujo de estados.
- Diseño adaptable a móvil.
